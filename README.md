# Radar de concursos — dados públicos

Lista de concursos usada pelo app **Lumen Plan**.

- **Fontes:** Instituto AOCP (lista pública de concursos do site da banca); Diário Oficial da União (Imprensa Nacional, in.gov.br, Seção 3) — editais e autorizações; PNCP (pncp.gov.br) — contratos de bancas para realizar concurso público (concursos previstos).
- **Somente concursos públicos** (federais, estaduais e municipais). Processos seletivos, vestibulares, residências e serviços acessórios ficam de fora.
- **Atualização:** automática, 2 vezes ao dia, pelo GitHub Actions (`.github/workflows/coletar.yml`).
- **Arquivo:** `concursos.json`.

Os dados são um resumo automático feito por regras (sem IA). Sempre confira o edital oficial no link de cada item.
